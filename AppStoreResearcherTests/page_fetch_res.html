    What’s New

    Sep 5, 2024

    Version 4.0

    Version 4.0 brings a fully optimized Apple Watch experience and an upgraded sync system—20+ updates we think you’ll love!

    Apple Watch Features
    • Supports the Pomodoro Technique, including Pomodoro cycle, reset, and more.
    • Compatible with all Apple Watch models.
    • Supports watch face complications, including full Pomodoro timer functionality.
    • Works independently from your iPhone. Timer status and data automatically sync quickly to iPhone via iCloud.
    • Allows you to create and edit tags directly on the Watch, and set focus durations.
    • Start timers faster. All focus tasks are displayed on the first screen.
    • Focus tasks can be sorted by recent activity.
    • Focus tasks support customizable durations and automatically remember the last duration used.
    • Apple Watch haptic feedback. Key actions like start, stop, and completion come with dedicated haptic feedback, enhancing the Watch experience.
    • Two focus modes: Pomodoro Technique and numeric.
    • Supports skipping breaks.
    • Watch face complications support color modes.
    • Interactive notifications. Rest or start the next timer directly from notifications without opening the app.
    • Different tags come with a dedicated color for their focus mode.

    4.0 Other Updates
    • Data sync update. Cross-device syncing is now more stable and faster.
    • Home screen widgets can now start Live Activities without opening the app.
    • Improved widget click feedback.
    • Optimized tag list view. The tag page now opens in full screen for easier access.
    • Fixed an issue where white noise would automatically pause when exiting and re-entering the app.
    • Fixed visual issues when Live Activities automatically switch between light and dark modes.
    • Removed the confirmation pop-up when abandoning a Pomodoro, and focus time will now be recorded by default, simplifying the experience.
    • Improved translations. Thanks to everyone who provided feedback.
    • Color adjustments for better readability and clarity.

    Mel2897 , 10/28/2023

    Love the app

    Love the app! Been using it around 2 weeks now and it makes it much easier for me to focus on tasks that don’t necessarily have end dates/times. I’ve always struggled with ongoing things like cleaning or responding to work emails but this helps me give tasks like these a finite amount of time as opposed to feeling like they’re looking over me indefinitely. Instead of being like “oh no I have 100 emails I need to get through” I can instead just be like “I am spending the next 25 minutes on emails.” I get so much more done with so much less existential dread. And it gives me a sense of accomplishment that just powering through part my inbox doesn’t. I also like that the app doesn’t force you to shut everything down to use it. I’ve used apps like that in the past and found them helpful but not the right fit for me.

    Lilycat14 , 04/28/2024

    Great app

    This app is great for the standard pomodoro user, and i love watching my tomatoes collect on the main screen after each session. It is very satisfying and motivating! There are some features i think should be added. Under the pomodoro technique section of the settings, there are options to change the length of the short and long breaks, but no way to change the length of the focus sessions. This would make the app alot more customizable and usable by more people for more purposes. I also find the labeling confusing for the focus session settings. The default setting of “3” i believe has 3 short breaks before the long break but the wording is odd and confusing and should offer a description or change to reflect its true meaning.

    I know more color themes are in development now but the devs should consider maybe different fruits/characters to accumulate on your screen as well if at all possible. overall, this app is my personal favorite for tracking my use of the pomodoro method and i hope to watch the app continue to grow and expand.

    NickyNaymes , 10/06/2023

    A nice app with a lot of potential

    So this is a new app, and it’s been great so far. Has a ton of potential, and I’m happy to use it in its current state, but here is some stuff I would like

    1. After a session ends, option to break *or* transfer to stopwatch mode, for when you aren’t quite ready. Then you can just break when you’re ready
    2. Way to pause the pomo. I get that this isn’t really the Pomo method or whatever, and some penalization can happen, but real life does happen and that would be a great option
    3. Instead of clicking the notification, I’d like to be able to transfer between focus and break states from the live activity. Flow supports this and it’s great.
    4. A way to get the session history out of the app in a programmatic way. Maybe a shortcut action for this, like things 3’s find action
    5. A way to add a text description (eg. “Summarize meeting notes” instead of a general label like “Writing”)
    5.1 Maybe, these labels could be pulled *from* things? I see this is on the Flow roadmap. Then I can see how long I spent on each task

    Personally I don’t care about all the self control stuff like blocking ect, and these suggestions are all minutia, but add up to a gigantic improvement. Just some food for thought. Nice work.
